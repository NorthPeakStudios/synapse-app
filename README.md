# Synapse (web)

The web version of Synapse, a medicine study app by Northpeak Studios: flashcards with spaced repetition, courses, Doctordle and anatomy.

Open it: https://northpeakstudios.github.io/synapse-app/

The app's server (accounts, sync, deck library, purchases) runs separately; this repository holds the static front end only.
