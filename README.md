# Synapse app (Android + iOS)

The native app for **Synapse** (the study app at https://odin-cards.sites.tab.bot/), by Northpeak Studios.

| File | What it's for |
|---|---|
| `GITHUB.md` | Put this project on GitHub and run the builds. Odin can do this himself (GitHub allows 13+). |
| `CHECKLIST.md` | Publishing on **Google Play**: the parent's steps, the costs and the timeline. Apple is listed second. |
| `SIDELOAD.md` | Install the iPhone build on Odin's own phone from a Windows laptop with a free Apple ID. |
| `BUILD.md` | How the build works, live updates, store mode, and what needs a new build. |
| `LICENSES.md` | Third-party content and whether each is OK for a store. |
| `store/google-play/` | Play listing kit: icon, feature graphic, screenshots, listing text, data safety and content rating answers. |
